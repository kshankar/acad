A USM Innovation Seed Fund project to design a black-box cyber security monitoring agent device for network environments.

<!--more-->

This project designs and develops a black-box based agent device for cyber security monitoring, forming an early building block towards operational security monitoring capabilities later realized in [OwlSight](https://www.bitranger.io).

Project Duration: **15/08/2022-14/08/2023**

Funding: RM 10,000.00, Innovation Seed Fund (Internal, University)
