A multi-year industry-funded research thread (BJIM) developing modular automation software and its secure integrative control for SECS/GEM-based production line testing.

<!--more-->

This ongoing collaboration with industry (BJIM) has progressed through several funded phases:
- **Modular Automation S/W** (External Grant Industry, RM 30,000.00, 30/11/2020-29/10/2026)
- **Integrative Control Software for SECS/GEM Module** (Match NG Grant Industry, RM 38,300.00, 01/04/2022-31/10/2024)
- **Feasibility of Secure Modular Automation Software in an Actual Production Line Environment** (Bridging Grant - Mentor, RM 25,000.00, 01/09/2025-31/08/2026)
- **Modular Automation S/W - Production Line Testing** (External Grant Industry, RM 49,050.00, 01/03/2026-30/11/2026)
